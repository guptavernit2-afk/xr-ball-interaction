# XR Ball Interaction

Unity 2022.3.62f2 workshop project by Vernit Gupta. The scene contains a moving sphere, an Oculus Interaction Sample Rig, and an in-world control panel.

Open the extracted project folder in Unity Hub with Android Build Support installed. Open Assets/Scenes/SampleScene.unity. The saved build target for the workshop was Android for the Meta Quest headset.

The ball is moved by Assets/scripts/SineWaveMovement.cs. It swings along X, travels forward and back along Z, and keeps its height. Assets/scripts/BallControlPanel.cs builds controls for speed, travel range, side swing, and frequency.
